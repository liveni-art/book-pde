# 6.1 Уравнение переноса с условием в конечный момент времени Т
Возвращаясь к более привычным обозначениям $(t,x)$ для общего квазилинейного уравнения первого порядка:
$$b(t,x,u)\cdot\nabla u = f(t,x,u), \qquad u = \bar u \text{ при } \{t=0\}.$$

**Постановка задачи.** Пусть $b=b(x)$ (линейный случай: не зависит от $u$), $f\equiv 0$, $n=1$ (одна пространственная переменная). Пусть $X(s;t,x)$ решает
$$\dot X(s) = b(X(s)), \qquad X(t)=x,$$
и определим
$$u(t,x) := \bar u\big(X(T;t,x)\big) \qquad (T \text{ фиксировано}).$$
**Утверждение:** эта функция $u$ решает
$$u_t + b(x)u_x = 0, \qquad u(T,x) = \bar u(x)$$
— т.е. задачу Коши с данными, заданными в *конечный* момент времени $T$, а не при $t=0$.

```
 t
 T +---------●--- (данные ū заданы ЗДЕСЬ, при t = T, а не при t=0)
   |        /
   |       /  <- характеристика движется вперёд от (t,x) до (T, X(T;t,x))
   |      /
   t +---●
   |    x
 0 +------------------> x
```


**Замечание о дивергентной форме:** закон сохранения $u_t+(f(u))_x = 0$ буквально является $\operatorname{div}_{(t,x)}\eta = 0$ для $\eta=(u,f(u))$ — бездивергентное векторное поле в пространстве-времени, что сигнализирует о сохраняющейся величине. (Для сравнения: даже *линейное* уравнение переноса $u_t+b\cdot\nabla u=0$ не обязательно имеет такую дивергентную форму, если только $b$ само не бездивергентно.)

$b=b(x)$ — векторное поле. Пусть $X(s;t,x)$ решает характеристическое ОДУ
$$\dot X(s) = b\big(X(s)\big), \qquad X(t) = x,$$
(траектория, проходящая через $x$ в момент $t$, вычисленная в момент $s$). Определим
$$u(t,x) := \bar u\big(X(T;t,x)\big).$$

**Утверждение.**
$$u_t + b\cdot\nabla u = 0, \qquad u(T,x) = \bar u(x).$$

**Условие в конечный момент времени.** $X(T;T,x)=x$ тривиально (поток нулевой длительности), поэтому $u(T,x)=\bar u(x)$. ✓

**Свойство полугруппы потока**, для $0\le t\le\tau\le s\le T$:
$$X(s;t,x) = X\big(s;\tau,\,X(\tau;t,x)\big).$$

```
      t          τ          s
  x ──●──────────●──────────●
      \_________/ \________/
       X(τ;t,x)     X(s;τ,·)
      \_______________________/
             X(s;t,x)
```

 **Полное дифференцирование тождества полугруппы.**
 Зафиксируем $t,x$ и положим $s=T$. Тождество полугруппы утверждает, что для каждого $\tau\in[t,T]$
 $$X\big(T;\,\tau,\,X(\tau;t,x)\big) = X(T;t,x) \qquad \text{(не зависит от $\tau$, в силу самого свойства полугруппы).}$$
 Определим $A(\tau) := X\big(T;\tau,\,y(\tau)\big)$, где $y(\tau):=X(\tau;t,x)$. Тождество говорит, что $A(\tau)$ не зависит от $\tau$, поэтому $A'(\tau)\equiv 0$. Продифференцируем, рассматривая $X(T;\tau,y)$ как функцию двух аргументов $\tau$ и $y$, а затем подставляя $y=y(\tau)$):
 $$0 = A'(\tau) = \partial_\tau X(T;\tau,y)\Big|_{y=y(\tau)} \;+\; \nabla_y X(T;\tau,y)\Big|_{y=y(\tau)} \cdot y'(\tau).$$
 По определению характеристического ОДУ, $y'(\tau) = \dot X(\tau;t,x) = b\big(X(\tau;t,x)\big) = b(y(\tau))$. Итак, для каждого $\tau\in[t,T]$:
 $$0 = \partial_\tau X(T;\tau,y(\tau)) + \nabla_y X(T;\tau,y(\tau))\cdot b(y(\tau)).$$
 Теперь положим $\tau=t$: поскольку $y(t) = X(t;t,x) = x$,
 $$0 = \partial_\tau X(T;\tau,x)\Big|_{\tau=t} + \nabla_x X(T;t,x)\cdot b(x).$$
 

Далее, дифференцируя $u(t,x)=\bar u(X(T;t,x))$:
$$u_t(t,x) = \bar u'\big(X(T;t,x)\big)\cdot \partial_t X(T;t,x),$$
$$\nabla u(t,x) = \bar u'\big(X(T;t,x)\big)\cdot \nabla_x X(T;t,x).$$
Умножая (14) на $b(x)$ и подставляя $\nabla_x X(T;t,x)$ из (12):
$$b(x)\cdot\nabla u(t,x) = \bar u'\big(X(T;t,x)\big)\cdot\big(-\partial_t X(T;t,x)\big) = -u_t(t,x).$$
Следовательно, $u_t + b\cdot\nabla u = 0$. $\blacksquare$

---

Идея: 

- начать в момент $t$, в точке $x$; 
- провести характеристическое ОДУ вперёд до фиксированного конечного момента $T$; 
- вычислить там заданные конечные данные $\bar u$. 

Утверждение состоит в том, что это определяет (единственное) решение линейного уравнения переноса 
с *конечным* условием при $t=T$, а не с начальным условием при $t=0$.

Условие в конечный момент: движение потока в течение нулевого времени ничего не меняет. 

Для проверки самого УрЧП используем свойство полугруппы потока: разбиение траектории от $t$ до $s$ на участок от $t$ до промежуточного момента $\tau$, а затем от $\tau$ до $s$, даёт ту же самую конечную точку в силу единственности решений ОДУ. 

Дифференцирование этого тождества по промежуточному времени $\tau$ с последующей подстановкой $\tau=t$ даёт в точности соотношение, необходимое для того, чтобы члены с производной по времени и по пространству у $u$ сократились друг с другом.

Запись уравнения с пространственной производной, применённой к $f(u)$, а не с прямым умножением на $u_x$, делает его чистой дивергенцией в пространстве $(t,x)$ — это позволяет придать смысл решениям после образования сингулярности, поскольку уравнение в дивергентной форме допускает формулировку через интегрирование по частям (слабую формулировку).


## 6.2 Уравнение Бюргерса и образование ударной волны 


> $$u_t + uu_x = 0, \qquad u(0,x) = \bar u(x) = \frac{1}{1+x^2}.$$

Если нарисовать характеристики для этих данных, то две характеристики, начинающиеся в разных точках, могут пересечься за конечное время. В точке пересечения построение $u(t,x):=y(s(x),\sigma(x))$ пытается приписать два разных значения $u$ одной и той же точке $(t,x)$ — метод перестаёт работать начиная с этого момента. Это называется **образованием сингулярности**; это может произойти даже при гладких ($C^1$) начальных данных. 

Если записать в стандартном виде $u_t + f'(u)\,u_x = 0$, то $\qquad f(y) = \frac{y^2}{2}$


Параметризуем начальную линию $\Sigma=\{t=0\}$ как $\varphi(\sigma) = (0,\sigma)$, отождествляя $\sigma\leftrightarrow x$.

**Характеристическая система** (неизвестные $x_1$ = время, $x_2$ = пространство, $y$ = значение $u$ вдоль характеристики):
$$\dot x_1 = 1, \qquad \dot x_2 = y, \qquad \dot y = 0,$$
$$x_1(0)=0,\quad x_2(0)=\sigma,\quad y(0) = \bar u(\sigma) = \frac{1}{1+\sigma^2}.$$

**Решение:**
$$y(s,\sigma) = \frac{1}{1+\sigma^2}\ \text{(постоянна по $s$)}, \qquad x_1(s,\sigma) = s, \qquad x_2(s,\sigma) = \frac{s}{1+\sigma^2}+\sigma.$$

**Замена переменных** $(s,\sigma)\mapsto(t,x)$: $t=s$, $x = \dfrac{t}{1+\sigma^2}+\sigma$. Это локальный диффеоморфизм вблизи $\Sigma$, но **не обращается явно** — решение относительно $\sigma(t,x)$ требует решения кубического уравнения по $\sigma$:
$$x = \frac{t}{1+\sigma^2}+\sigma \iff (x-\sigma)(1+\sigma^2) = t \iff \sigma^3 - x\sigma^2 + \sigma - x + t = 0.$$
Разрешимо относительно $\sigma(t,x)$ лишь локально, при $t$ меньше некоторого критического $T_{\text{sing}}$.

**Почему это локальный диффеоморфизм, и где обратимость нарушается.**
Запишем $\Phi(s,\sigma) = \big(s,\; \frac{s}{1+\sigma^2}+\sigma\big) = (t,x)$. Его матрица Якоби (строки: $\partial_s,\partial_\sigma$ каждой компоненты) равна
$$D\Phi(s,\sigma) = \begin{pmatrix} \partial_s x_1 & \partial_\sigma x_1 \\ \partial_s x_2 & \partial_\sigma x_2\end{pmatrix} = \begin{pmatrix} 1 & 0 \\[2pt] \dfrac{1}{1+\sigma^2} & 1 - \dfrac{2s\sigma}{(1+\sigma^2)^2} \end{pmatrix},$$
используя $\partial_\sigma\!\left(\dfrac{s}{1+\sigma^2}\right) = -\dfrac{2s\sigma}{(1+\sigma^2)^2}$. Следовательно
$$J(s,\sigma) := \det D\Phi(s,\sigma) = 1 - \frac{2s\sigma}{(1+\sigma^2)^2}.$$
При $s=0$ (т.е. на самой $\Sigma$), $J(0,\sigma)=1\ne 0$ для любого $\sigma$ — по теореме об обратной функции, $\Phi$ является диффеоморфизмом из окрестности $(0,\sigma)$ на окрестность $(0,x)$ на плоскости $(t,x)$, для каждого $\sigma$. Это и есть утверждение о «локальном диффеоморфизме вблизи $\Sigma$».

Поскольку $J$ непрерывно зависит от $(s,\sigma)$ и равно $1$ при $s=0$, оно остаётся строго положительным при малых $s=t$, равномерно на любом ограниченном диапазоне $\sigma$, и может обратиться в нуль лишь при достаточно большом $t$ (т.е. $s$). Решая $J(t,\sigma)=0$ относительно порогового значения $t$ как функции от $\sigma$:
$$1 = \frac{2t\sigma}{(1+\sigma^2)^2} \iff t = \frac{(1+\sigma^2)^2}{2\sigma} \qquad (\sigma>0 \text{ необходимо для } t>0).$$
Назовём это $\tau(\sigma)$; это в точности момент времени, когда отображение $\Phi$ перестаёт быть локально обратимым **вдоль характеристики, начинающейся в $\sigma$**. Минимизация по $\sigma>0$ даёт первый момент столкновения *любой* пары характеристик:
$$T_{\text{sing}} = \min_{\sigma>0} \tau(\sigma) = \min_{\sigma>0}\frac{(1+\sigma^2)^2}{2\sigma}.$$
Дифференцируя $\tau(\sigma)$ по $\sigma$ и приравнивая к $0$: при $\tau(\sigma) = \frac{1}{2}\sigma^{-1}(1+\sigma^2)^2$,
$$\tau'(\sigma) = \frac{1}{2}\left[-\sigma^{-2}(1+\sigma^2)^2 + \sigma^{-1}\cdot 2(1+\sigma^2)\cdot 2\sigma\right] = \frac{(1+\sigma^2)}{2\sigma^2}\Big[-(1+\sigma^2) + 4\sigma^2\Big] = \frac{(1+\sigma^2)(3\sigma^2-1)}{2\sigma^2}.$$
Это обращается в нуль (при $\sigma>0$) при $\sigma = 1/\sqrt3$

**Неявное решение** (при $t<T_{\text{sing}}$):
$$u(t,x) = \frac{1}{1+\sigma(t,x)^2}, \qquad \text{где } \sigma(t,x) \text{ решает } x = \sigma + \frac{t}{1+\sigma^2}.$$

**Характеристики на плоскости $(t,x)$:** при фиксированном $\sigma$ прямая
$$x(t) = \sigma + \frac{t}{1+\sigma^2}$$
проходит через $(0,\sigma)$ с угловым коэффициентом $\dfrac{dx}{dt}=\dfrac{1}{1+\sigma^2}=\bar u(\sigma)$.

```
 t                                       t
 ^           \   |   /                   ^
 |            \  |  /                    |    все прямые выходят
 |             \ | /                     |    из t=0, наклон = ū(σ)
 |              \|/    <- пересечение    |
 |               X       (удар. волна,   |     \   |   |   /
 |              /|\        x>0)          |      \  |  |  /
 |             / | \                     |       \ | | /
 |            /  |  \  <- прямые         |
 |           /   |   \    расходятся     |
 0---------------+--------------> x      |    (x<0, без
              σ = 0                      |     ударной волны)
```

Поскольку $\bar u(\sigma)=1/(1+\sigma^2)$ чётна, с максимумом при $\sigma=0$ и строго убывает при $\sigma>0$: со стороны $x>0$ характеристики с меньшим $\sigma$ *быстрее* характеристик с большим $\sigma$ и догоняют их — они **пересекаются** за конечное время. Со стороны $x<0$ скорость возрастает с ростом $\sigma$ (по направлению к $0$), поэтому характеристики **расходятся** — там пересечения не происходит.

**Время образования сингулярности** $T_{\text{sing}}$: первый момент, когда встречаются две характеристики; эквивалентно, первый момент, когда обращается в нуль якобиан отображения $(t,\sigma)\mapsto x$. Здесь $T_{\text{sing}}>0$ (мгновенной сингулярности нет — решение остаётся настоящей функцией/графиком в течение положительного промежутка времени).

**Эволюция профиля** (схематично):

```
u                                    u
|      ___                           |        |
|     /   \      (t = 0)             |       /|          (t = T_sing)
|    /     \                         |      / |   передний фронт
|___/       \___          --->       |_____/  |___        становится
          x                                    x           вертикальным
```

При $t=T_{\text{sing}}$ график приобретает вертикальную касательную; после этого момента построение через характеристики сделало бы $u$ многозначной при $x>0$ (что не принимается как решение).

**Препятствие к продолжению после $T_{\text{sing}}$:** если у $u$ образуется скачок разрыва, $u_x$ становится мерой типа дельта-функции Дирака, и произведение $u\,u_x$ в *недивергентной* форме $u_t+uu_x=0$ оказывается плохо определённым (непрерывная функция, умноженная на сингулярную меру, вообще говоря, не имеет смысла). Это и есть мотивация записывать уравнение в **дивергентной форме (форме закона сохранения)**,
$$u_t + \left(\frac{u^2}{2}\right)_x = 0,$$
которая допускает распределительную (слабую, через интегрирование по частям) формулировку — отправную точку теории ударных волн и энтропийных решений, отмеченную как выходящую за рамки этого курса.

## 6.3 Принцип Дюамеля для линейного уравнения переноса


> Пусть $b\in\mathbb R^n$ постоянно, $F=F(s,x)$ задана (гладкая). Для $S\ge 0$ пусть $U(t,S,x)$ обозначает (единственное) решение **однородного** уравнения переноса с постоянными коэффициентами с данными, заданными в момент $S$ (а не $0$):
$$\partial_t U + b\cdot\nabla U = 0, \qquad U(S,x) = F(S,x).$$
>
> Определим
> $$V(t,x) := \int_0^t U(t,s,x)\,ds.$$
>
> **Тогда принцип Дюамеля:**
> $$V_t + b\cdot\nabla V = F, \qquad V(0,x) = 0.$$

*(Дифференцирование $V$ по $t$ даёт два вклада — один от верхнего предела интегрирования, другой от дифференцирования самой $U(t,s,x)$ по $t$; дифференцирование по $x$ проходит под знаком интеграла; при $t=0$ интеграл пуст, так что $V(0,x)=0$ сразу.)*

Сначала зафиксируем, чем на самом деле является $U(t,s,x)$: она решает $\partial_t U + b\cdot\nabla U = 0$ с $U(s,x)=F(s,x)$ (данные, заданные в момент $s$), т.е. это решение однородного уравнения переноса, перенесённое назад с момента $s$ на момент $0$:
$$U(t,s,x) = F\big(s,\,x + b(s-t)\big).$$
*(Проверка: при $t=s$, $U(s,s,x)=F(s,x)$. ✓. И $\partial_t U = -b\cdot\nabla F(s,\cdot)|_{x+b(s-t)}$, $\nabla U = \nabla F(s,\cdot)|_{x+b(s-t)}$, поэтому $\partial_t U + b\cdot\nabla U = -b\cdot\nabla F + b\cdot\nabla F = 0$. ✓.)*

Теперь продифференцируем $V(t,x)=\int_0^t U(t,s,x)\,ds$ по $t$, используя правило Лейбница (граничный член от переменного верхнего предела, плюс дифференцирование подынтегральной функции):
$$V_t(t,x) = U(t,t,x) + \int_0^t \partial_t U(t,s,x)\,ds.$$
Граничный член равен $U(t,t,x) = F(t,x)$ по определяющему свойству $U$ (данные на диагонали $s=t$ равны $F(s,x)$ там). Для производной по $x$ дифференцируем под знаком интеграла (граничного члена нет, поскольку пределы интегрирования не зависят от $x$):
$$\nabla V(t,x) = \int_0^t \nabla U(t,s,x)\,ds.$$
Объединяя:
$$V_t + b\cdot\nabla V = F(t,x) + \int_0^t \Big[\partial_t U(t,s,x) + b\cdot\nabla U(t,s,x)\Big] ds = F(t,x) + \int_0^t 0 \,ds = F(t,x),$$
используя, что $U(t,s,\cdot)$ решает *однородное* уравнение по $(t,x)$ при каждом фиксированном $s$. Это в точности заявленное УЧП, $V_t+b\cdot\nabla V = F$.

Наконец, $V(0,x) = \int_0^0 U(0,s,x)\,ds = 0$, поскольку промежуток интегрирования пуст. Этим завершается проверка домашнего задания.

Подстановка явного вида $U(t,s,x)=F(s,x+b(s-t))$ в определение $V$ в точности восстанавливает интеграл Дюамеля:
$$V(t,x) = \int_0^t F\big(s,\,x+b(s-t)\big)\,ds.$$

**Итак.** Для
$$u_t + b\cdot\nabla u = f, \qquad u(0,x)=\bar u(x),$$
решение имеет вид
$$u(t,x) = \bar u(x-bt) \;+\; \int_0^t f\big(s,\,x+b(s-t)\big)\,ds,$$
т.е. $u = $ (решение однородной задачи с начальными данными $\bar u$) $+$ (решение неоднородной задачи с **нулевыми** начальными данными, задаваемое формулой Дюамеля/суперпозиции выше).
